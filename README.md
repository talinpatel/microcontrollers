COMP22712 - Electric Piano Program


This code contains drivers, OS code and user code to run an Electric Piano program on a custom lab-designed RISC-V board, using an external keypad and buzzer peripheral.
This OS supports internal and external interrupts with a variety of ISRs, has separate user and machine code and stacks, and a large variety of peripheral drivers to interface with the HD44780 LCD display
./machine - OS code
./lib - Library code
./usr - User code
./peripherals - peripheral drivers
